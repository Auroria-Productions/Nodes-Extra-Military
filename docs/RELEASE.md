## Nodes Military 1.2.0

Open `/nmilitary` to browse your nation's armies. Leaders can create formations, appoint commanders and assign ranks in the menu. Citizens can enlist, inspect their division and check orders. Existing command aliases and schema-1 saves are supported.

- Install **Nodes-Military.jar** in `plugins/` alongside MilzzyNodes dev.5.11 and Vault. For a 1.0.0 or 1.1.0 upgrade, stop the server, back up `plugins/Nodes-Military/` and replace the addon JAR.
- **Nodes-Extra 1.1.0 is optional.** Installing it enables Marshal and government-head authority and depot supply reports. This release handles a custom Nodes-Extra state filename.
- **Nodes-Military-1.2.0-Source.zip** contains the source, default configuration, tests and build script for this release. Run `bash build.sh` with JDK 21.
